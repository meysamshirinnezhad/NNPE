# Images Directory

This directory contains static image assets for the NPPE Pro platform.

## Usage

Images placed in this directory can be referenced in components using paths like:
- `/images/filename.jpg`
- `/images/icons/icon-name.svg`
- `/images/logos/company-logo.png`

## Organization

- `icons/` - UI icons and small graphics
- `logos/` - Company and partner logos
- `backgrounds/` - Background images and patterns
- `avatars/` - Default user avatars
- `illustrations/` - Hero images and illustrations
- `testimonials/` - User testimonial images

## File Naming

- Use kebab-case for file names: `user-avatar.png`
- Include descriptive names: `hero-engineering-team.jpg`
- Add size suffix for multiple sizes: `logo-small.png`, `logo-large.png`

## Optimization

- Use appropriate formats (JPEG for photos, PNG for transparency, SVG for icons)
- Optimize images for web before adding
- Consider responsive images for different screen sizes
